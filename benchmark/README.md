# Benchmark

The product plan calls for reproducible scenarios with independently reviewed ground-truth labels, including irrelevant and hidden-dependency changes. Compare the deterministic engine with no guard and file-hash flagging before deciding whether the graph adds value.

`scenarios/` is reserved for those cases. The protocol, fixtures, runner, and results have not been created yet. See `docs/verix_prd.pdf` for the proposed evaluation and thresholds.
